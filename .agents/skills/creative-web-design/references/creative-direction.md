# 艺术方向与创意保留

## 建立方向

先写一句可被体验的核心概念，例如用户打开一册会改变空间的舞谱；再选择视觉与动效。不要用“高级、惊艳”代替具体体验。

方向未明时通常比较 2–3 个实质不同的方向。每个方向说明核心隐喻、空间构图、字体角色、画面材质、输入与交互、节奏、关键记忆点、素材需求和实现成本。至少在空间结构或交互叙事上不同，不能仅换颜色。已有明确参考/用户选择直接沿用。

优先用户参考与已有素材。需要外部案例时分析真实作品的构图、材质、字体、交互与转场机制，记录网址、查看日期、观察点和能取得的截图/原型。可参考 Awwwards、Godly、Codrops、Behance、React Bits、Rive；这些是研究来源，不是自动获得商用许可的素材库。无法联网或查看图像时写明证据限制。

有获准的图像能力时可以做概念图；否则在隔离产物目录制作局部 HTML/CSS 原型。真实交互须为页面元素，截图和概念图仅为方向证据。探索结果没有被用户选择前，保持 `unconfirmed`；授权代选须记录授权原话/来源及代选理由。

## 上游建议如何使用

读取 Taste 的实际入口，用它做连贯的艺术判断。当前标准 v2 的规则是情境性的，且其主要范围为展示/作品集/改造；不要将其营销结构套到所有教学、工作台或故事页面。

任务级展示起点可用 `8/7/3`；选择的值与理由写进方向文件，覆盖其默认值只在本任务的对话/记录中完成。不能为参数强行引入 GSAP、Three.js 或素材生成。

居中标题、卡片、Bento、玻璃拟态、fade-up、噪点和粒子均不是自动方案。用户明确方向需要时可使用；没有需要时寻找与核心概念相连的构图和交互。允许不对称、留白、超大字、拼贴、手绘、像素和非线性导航，同时保留内容理解与可操作路径。不要随机拼接无关风格。

## 锁定艺术特征

使用 `assets/templates/art-direction.md`，记录确认状态、来源和参考证据。必须分清：

- **必须保留：** 形成作品身份的空间、材质、字体关系、章节机制和角色连续性。
- **可调整：** 字号、对比度、资源格式、加载策略或具体实现库等细节。
- **禁止退化：** 用户不接受的结果，例如舞谱导航被换成通用 SaaS 卡片。

方向文件是决策事实源，session 只引用它。尊重现有 `DESIGN.md`，不要无故新增相互冲突的品牌文件；可将任务方向文件作为该文件的增量证据。

## 创意回归

Impeccable 的质量检查先将现象分类：有意表达、可证实的操作/可读性/性能缺陷、尚待验证的疑问。修正缺陷时保留其创意机制，例如保留偏心大字与撕纸转场，改善对比度、焦点和加载。

无法兼容时说明具体触发、设备证据、影响及保留核心意图的替代方案；在已有授权范围内解决可逆实现细节。会替换已确认艺术身份的选择形成方向检查点，不能默默简化成极简 SaaS，也不能借保留创意忽略不可操作问题。
