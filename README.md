# Ethnic Dance Project

民族舞蹈视频、人体姿态及动作文本数据集项目。

## 目录说明

- `data/raw_videos/`：原始视频
- `data/clips/`：切分后的动作片段
- `data/pose_2d/`：逐帧二维人体关键点
- `data/pose_3d_est/`：估计的三维关节坐标
- `data/captions/`：动作文本描述
- `outputs/pose_visualization/`：骨架可视化结果
- `outputs/logs/`：处理与运行日志
- `metadata/samples.csv`：样本索引和元数据
- `scripts/`：数据处理脚本
