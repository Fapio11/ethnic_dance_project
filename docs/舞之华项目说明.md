# 舞之华项目说明

更新：2026-10-11。供网站展示与讲解使用，内容以当前代码为准。

## 项目定位

舞之华将民族舞蹈影像、人体姿态和动作解说放在同一观看环境中，便于观察、整理和交流。网站保留数字化工作台、舞蹈资源库、动作分析、项目与合规四个模块。姿态和指标提供观察依据，不自动判定舞蹈水平、文化真实性或教学结论。

## 四个模块怎么用

**数字化工作台**：观看示范或上传本地视频，切换影像优先、均衡查看，通过同一进度控制原片与骨架。上传后等待处理任务完成，才能载入对应二维和估计三维姿态。本地演示片段供播放器体验，不意味着它已关联姿态结果。

资源库样本有独立的动作解说编辑区。普通文字按非空行展示，可自行写入时间；“00:00–00:05｜内容”目前整行显示，不会自动拆成时间标签。若需要独立时间标签，可使用 JSON 数组，例如 `[{"time":"00:00–00:05","text":"双臂舒展"}]`。保存写入当前样本；未保存草稿在本次页面会话中保留，刷新前需保存。

**舞蹈资源库**：检索编号、名称、民族、地区和核验状态。点击“选用”只切换当前样本，再点击工作台导航观看；点击“动作比对”则选中示范并进入动作分析。视频、姿态和解说能否使用，取决于记录关联的资料。核验标签来自数据库字段，页面不执行自动核验。

**动作分析**：先选示范，再上传学习者视频；也可选独立处理。有可用二维姿态的示范才能参与比对，后端还会检查对应文件。切换示范后需重新提交；已有结果不会改绑到新示范。独立处理仍可查看自身姿态、角度和识别指标。

**项目与合规**：介绍处理思路、资料概况和使用提醒。授权清单、内容分级和“专业复核：待开展”是说明文字，尚未接入授权材料管理、分级操作或专业审核流程。

建议先用 10–30 秒、单人全身、遮挡较少的视频。网页选择器提供 MP4 / WebM；服务另接受 MOV、AVI、MKV，但浏览器未必能播放。实际大小上限为 300 MiB。上传或连接失败时按页面提示重试；能预览原片不代表处理服务已经可用。

## 视频如何变成姿态

当前处理链为视频检查 → RTMPose 二维提取 → 遮挡与低置信度跳点修复、平滑 → MotionAGFormer 三维估计 → 指标计算与网页数据整理。

二维结果是画面中的 COCO-17 人体关键点；估计三维结果是模型依据二维序列推算的 H36M-17 骨架，用于观察相对姿态。它不等同于现场三维测量，不能直接当作真实空间距离或完整动作复原。

网页二维骨架展示原始提取坐标；修复后的二维坐标用于三维估计、指标计算和示范比对。因此骨架显示与指标采用的数据版本存在区别。自动处理链目前不生成动作解说，也不自动确认舞种、出处或专业评分。

## 指标怎样理解

| 指标 | 当前计算含义 |
| --- | --- |
| 帧数、时长、帧率 | 从上传视频读取的结构信息；异常帧率会回退为 25 FPS。 |
| 人体检出率 | 修复后的二维数据中，每帧至少一个关节点置信度达到 0.3 的帧占比；不代表完整骨架正确率。 |
| 平均置信度 | 修复后二维数据的关节点置信度均值；不代表动作准确度。 |
| 右肩展开角度 | 画面内右髋—右肩—右肘的二维夹角，曲线最多取 60 个样本点；视角会影响数值。 |
| 时间对齐帧数 | 两段视频各自均匀采样后的比较点数，最多 180；不是逐动作识别或节拍对齐。 |
| 归一化关节误差 | 以髋部为中心、肩髋宽度为尺度的二维关节距离均值，无厘米等长度单位。 |
| 右肩平均角度差 | 对齐样本之间右肩二维夹角的平均绝对差。 |

比对数值受拍摄方向、遮挡、衣饰、动作节奏和模型误差影响。误差较小只说明当前计算条件下更接近，不能推出“舞得更好”；民族舞蹈的风格、语境和教学判断仍需专业人员解释。

## 资料、授权与 AI 使用

资源库来自 MySQL 的舞蹈记录，项目目录另组织原始视频、二维坐标、估计三维坐标、动作描述和样本元数据。具体出处、采集者及授权范围应依据对应素材记录核对，不能用网页标签代替授权凭证。

“原始视频”和“二维姿态”数量分别统计 `has_video`、`has_pose_2d`。这两个标记只表示相关 URL / 路径字段是否非空，统计单位是记录，不验证文件存在、可播放、姿态质量或授权情况。

RTMPose 与 MotionAGFormer 用于模型推断，遮挡修复和指标计算由处理脚本完成。解说可由人工编辑或粘贴外部内容；编辑器不会自动识别它是否由 AI 生成。对外讲解时应说明实际使用的模型及文本来源，AI 整理内容也需要核对原始资料。

## 当前实现与展示边界

普通网页上传建立独立任务，文件与产物存放在服务所在机器的任务目录；前端默认不要求入库，也不会覆盖资源库样本或自动增加其统计数量。后端已有针对既有样本回写结果的可选参数，当前网页没有入库操作入口。

前端具有资料读取、上传、任务进度、姿态展示、指标比对和解说保存的接口实现；实际使用需要后端、数据库、模型权重和关联文件同时可用。当前本地预览使用 5185 端口，前端默认请求 `127.0.0.1:8765`。连接状态以当次页面反馈为准，接口存在不等于端到端运行已验证。

资料未连接时保留原有已读记录，数量可能仅反映上次读取；空库、没有搜索结果、文件载入失败是不同状态。展示前应确认所用样本、播放器、姿态文件、任务结果和保存动作实际可用。

### 处理状态与动画

上传请求仍使用原有可取消 fetch 和任务轮询。上传没有字节级进度；后端的 progress 数字是阶段里程碑，也不是逐帧统计。因此前端不再显示原来的固定上传 1% 和阶段百分比，改为实际 stage 驱动的五个节点：上传、二维提取、质量修复、三维估计、整理结果。处理中使用无百分比的流动提示线，完成以服务返回的 completed 为准，失败和连接中断停止流动。未知阶段不推断已完成步骤。

当前舞者是现有静态插画降级素材。Seedance 的正式循环片段、收势片段尚未提供，不能把带固定百分比或文字的视频直接嵌入进度组件。接入时舞者视频只提供装饰，阶段、状态、按钮由前端单独控制，并保留减少动态效果、不可见暂停和素材失败降级。

资源库未连接继续展示真实错误与重试；不添加示例资源、假统计、合规认证章。页面文案保持精简，解释集中于本文档。

### 首页影像工作台：换位与页内放大（2026-10-11）

三张卡片可以从标题栏拖动交换位置，左侧为主视图；右上角的图钉也可直接设为主视图。展开图标进入页内专注观看，另外两张保留为辅助画面；「还原布局」或 Escape 恢复原排列。支持均衡查看、重置和本机排列偏好记忆。卡片换位和设为主视图不依赖数据状态，未生成结果的空卡片也可调整位置；页内放大需等待内容就绪。整个标题栏（右侧操作按钮除外）可起拖，专注模式先还原布局再拖动。

拿起卡片时显示轻量浮动标题，落点显示赭红边框；选中状态通过书签、标题底线和阴影强调。换位和放大采用 420 ms 缓出位移缩放过渡，遵循系统减少动态效果设置。键盘可在标题按钮上按空格拿起、方向键选择目标、回车放下、Escape 取消，手机也可用主视图与放大按钮。

三张媒体保留固定 React 容器与同一个原片 video 节点，CSS Grid 改变显示位置，Canvas 继续从原片时间读取对应帧。Canvas 监听尺寸变化，在暂停时也重新绘制，并根据容器大小和设备像素比调整绘制分辨率。第一版不包含拖分隔线调整比例，也不新增分析接口或模型流程。
